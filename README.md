# SMPN 1 SALATIGA

Aplikasi sekolah mobile yang dibuat mengikuti mockup yang diberikan.

## Run app

```bash
npm install
npm start
```

## Fitur utama

- Tampilan beranda sekolah
- Menu utama SMPN 1 Salatiga
- Absensi siswa dan pegawai
- Scan siswa
- Riwayat kehadiran
- Fitur tambahan seperti jurnal, penilaian, materi, dan laporan

## Stack

- React Native
- Expo
