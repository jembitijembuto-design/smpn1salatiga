# SMPN 1 SALATIGA

Aplikasi sekolah interaktif berbasis React Native / Expo untuk SMP N 1 Salatiga.

## Fitur yang tersedia
- Dashboard utama sekolah
- Daftar siswa dan jumlah kelas
- Modul ajar
- Kompetensi siswa
- Lembar kerja siswa
- Materi & TKA
- Ujian online
- Absensi siswa
- Jurnal guru
- Penilaian
- Pelanggaran siswa
- Report / rapor
- Profil dan logout

## Menjalankan aplikasi

```bash
npm install
npm start
```

Lalu pilih platform Android/iOS melalui Expo CLI.
